# box-proxy 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 实现专网 HTTP 接口录制（正向代理）与离线重放工具 `box-proxy`，默认数据目录 `./box-proxy-api`（支持软链接切换）。

**架构：** 单二进制 + 两个子命令（record/replay）。录制为 hyper HTTP/1.1 正向代理，原样保存请求/响应快照并下载静态资源（sha256 去重）；重放按 method+path 匹配快照，回传改写后的响应与本地资源，零外网。

**技术栈：** Rust 2024 edition、tokio、hyper 1.x（仅 http1）、hyper-util、serde/serde_json、regex、sha2、base64、mime_guess、clap、tracing、anyhow。

**设计文档：** `docs/superpowers/specs/2026-08-01-box-proxy-design.md`

```rust
#[derive(Parser)]
#[command(name = "box-proxy", version, about = "专网HTTP接口录制与离线重放代理工具")]
pub struct Cli {
    #[command(subcommand)]
    pub command: Command,
}

#[derive(Subcommand)]
pub enum Command {
    Record(RecordArgs),
    Replay(ReplayArgs),
}

#[derive(Args)]
pub struct RecordArgs {
    #[arg(short, long, default_value_t = 8888)]
    pub port: u16,
    #[arg(short, long, default_value = "./box-proxy-api")]
    pub dir: PathBuf,
    #[arg(long)]
    pub rewrite_on_record: bool,
    #[arg(short, long, action = ArgAction::Count)]
    pub verbose: u8,
}

#[derive(Args)]
pub struct ReplayArgs {
    #[arg(short, long, default_value_t = 8080)]
    pub port: u16,
    #[arg(short, long, default_value = "./box-proxy-api")]
    pub dir: PathBuf,
    #[arg(long, value_enum, default_value_t = RewriteMode::Relative)]
    pub rewrite: RewriteMode,
    #[arg(long, default_value = "http://127.0.0.1:8080/")]
    pub absolute_base: String,
    #[arg(short, long, action = ArgAction::Count)]
    pub verbose: u8,
}

#[derive(Clone, Copy, ValueEnum, PartialEq)]
pub enum RewriteMode { Relative, Absolute, None }
```

```rust
pub enum RewriteRule { Relative, Absolute { base: String }, None }

static URL_RE: Lazy<Regex> = Lazy::new(|| {
    Regex::new(r"(?i)\bhttps?://([a-z0-9.\-]+)(?::(\d{1,5}))?((?:/[^\s\"'<>(){}]*)?)")
        .unwrap()
});

pub fn rewrite_text(input: &str, rule: &RewriteRule) -> String;
pub fn extract_http_urls(text: &str) -> Vec<String>; // 去重，保持出现顺序
```

### 任务 4：录制正向代理（record.rs）

**文件：**
- 创建：`src/record.rs`
- 修改：`src/main.rs`

- [ ] **步骤 1：实现 record server**

- `run(cfg)`：绑定监听端口，`TcpListener` + hyper server（http1_only + keep_alive）。
- handler：解析请求 URI——
  - 有 authority（absolute-form）：取 scheme/host/port；
  - scheme 非 http → 501 响应并记录日志；
  - 否则按 origin-form 转发，Host 头覆盖为目标 authority。
- 转发：hyper-util `legacy::Client`（http1_only），超时 30s；`collect()` 请求体与响应体。
- 保存快照（原样）→ `--rewrite-on-record` 时改写后回传，否则原样回传；日志一行。
- 返回响应时剥离 hop-by-hop 头（transfer-encoding 等交给 hyper 重建）。

- [ ] **步骤 2：集成测试（tests/proxy_flow.rs）**

### 任务 6：离线重放服务（replay.rs）

**文件：**
- 创建：`src/replay.rs`
- 修改：`src/main.rs`

- [ ] **步骤 1：实现匹配与响应**

- 启动：`load_snapshots(dir)` + 加载 index.json 静态资源映射（path → blob）。
- 索引：`HashMap<(String origin, String method, String path, String query), Vec<usize>>`。
- 匹配顺序：Host 精确 → 忽略 origin 兜底；歧义取 seq 最大；均无 → 静态资源 → 404。
- 命中：原状态码 + `rewrite_text` 改写 body（按 CLI 模式）+ 原 Content-Type（缺省 mime_guess）+ 剥离 hop-by-hop 头。
- 静态：blob 字节 + mime_guess Content-Type。
